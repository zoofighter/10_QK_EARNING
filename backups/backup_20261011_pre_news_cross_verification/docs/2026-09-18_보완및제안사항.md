# QK_EARNING — 보완 및 제안 사항 (2026-09-18)

현재까지 Phase 1 기반 구축이 완료된 상태입니다. 아래는 **즉시 구현 가능한 단기 보완**부터 **중장기 확장**까지 우선순위별로 정리한 사항입니다.

## 🔴 단기 보완 (지금 당장 구현 가능 — Phase 1.5)

### 1. 수집된 Filing 원문 자동 다운로드 및 텍스트 파싱

**현재 상태**: SEC EDGAR 메타데이터(Accession No., 날짜 등)만 수집. 실제 원문 텍스트는 미수집.  
**문제**: "Filing 상세 열람" 클릭 시 raw_text가 비어 있음.

**제안**:
- `edgar_collector.py`의 `download_docs=True` 모드를 완성
- BeautifulSoup으로 HTML → 순수 텍스트 추출 → `filing.raw_text`에 저장
- FTS5 인덱스와 연동하여 전문 검색 즉시 활성화

---

### 2. Beat/Miss 대시보드 구현

**현재 상태**: DB 스키마(`consensus` 테이블)만 존재. UI 없음.  
**왜 중요한가**: 프로젝트의 핵심 기능 중 하나이며, 실적 시즌(10월)이 바로 앞.

**제안**:
- 컨센서스 데이터 수동 입력 폼 (Ticker, 분기, EPS 컨센서스, 매출 컨센서스)
- 실제 실적 입력 시 자동 판정: BEAT / INLINE / MISS
- 히트맵 시각화: 행=기업, 열=분기, 색=Beat/Miss
- 어닝 후 주가 반응(1d/5d) 자동 계산: `stock_price` 테이블과 조인

---

### 3. 어닝콜 트랜스크립트 수집 파이프라인

**현재 상태**: `earning_call` 테이블 존재, 수집기 없음.  
**소스 우선순위**:

| 방법 | 특징 | 비용 |
|------|------|------|
| SEC 8-K Exhibit 99.x 크롤링 | 공식, 무료, 구조화 필요 | 무료 |
| Motley Fool Transcripts 크롤링 | 정제된 텍스트 | 무료(수동) |
| Earnings Whispers API | 구조화된 트랜스크립트 | 유료 |
| AlphaStreet / Quartr | 최고 품질 | 유료 |

**제안**: 8-K Exhibit 99.1 자동 파싱부터 시작 → 부족분 수동 입력

---

### 4. 핵심 재무지표 자동 추출 (Financial Metric Extractor)

**현재 상태**: `financial_metric` 테이블 존재, 추출 로직 없음.  
**제안 구현 방법**:
- XBRL 데이터 활용: `edgartools` 라이브러리 추가 설치
- 추출 대상: Revenue, EPS, Operating Income, CapEx, Gross Margin, Guidance
- 규칙 기반 정규식 → 실패 시 LLM 보정 (선택)

---

### 5. 관세청 공공데이터포털 API 자동 수집

**현재 상태**: 수동 입력만 가능.  
**자동화 조건**: 공공데이터포털(`data.go.kr`) 인증키 발급 (무료, 1~2일 소요)  
**구현**: `kr_export_collector.py`에 `collect_from_api(api_key)` 메서드 추가  
**호출 파라미터**:
- `hsSgn`: `8542` (전자집적회로/반도체)
- `strtYymm` / `endYymm`: 수집 기간 지정
- 응답 형식: JSON / XML

---

### 6. `.env` 환경변수 파일 및 시크릿 관리

**현재 상태**: API 키, User-Agent 등이 `config.py`에 하드코딩 위험.  
**제안**:
```
# .env 파일
SEC_USER_AGENT=YourName contact@email.com
CUSTOMS_API_KEY=your_data_go_kr_key
OPENAI_API_KEY=sk-...
CLAUDE_API_KEY=sk-ant-...
```
- `.gitignore`에 `.env` 추가 필수
- `python-dotenv` 패키지는 이미 설치됨

## 🟡 중기 확장 (Phase 2~3 — 2~4주)

### 7. 어닝콜 키워드 분석 자동화

**제안 키워드 그룹 및 선행지표 의미**:

| 그룹 | 키워드 | 선행지표 의미 |
|------|--------|-------------|
| AI 수요 | AI, inference, training, data center | NVDA/AMD 수요 강도 |
| CapEx | capital expenditure, infrastructure investment | 하이퍼스케일러 투자 의향 |
| 공급망 | supply chain, lead time, allocation, tight | L4 파운드리 업황 |
| 수익성 | gross margin, pricing power, ASP | 업사이클/다운사이클 판단 |
| 재고 | inventory, digestion, correction | 메모리 현물가 선행 |
| 중국 | China, export control, restriction | 규제 리스크 |
| 가이던스 | guidance, outlook, next quarter | 컨센서스 방향 |

**구현**: 어닝콜 텍스트 입력 시 키워드 자동 카운팅 + 분기별 트렌드 차트

---

### 8. 레이어 간 상관관계 분석 (밸류체인 교차 분석)

**아이디어**: AI 투자 사이클의 흐름을 레이어 순서대로 추적

```
하이퍼스케일러 CapEx 증가
→ L4 파운드리 수주 증가 (TSMC 월매출 ↑)
→ L3 GPU 수요 증가 (NVDA 매출 ↑)
→ L5 메모리 수요 증가 (SK하이닉스 HBM 출하)
→ 한국 반도체 수출 순별 ↑
```

**구현**: 레이어별 핵심 지표의 시계열을 같은 차트에 오버레이

---

### 9. 실적 서프라이즈 → 주가 반응 자동 분석

**아이디어**: 어닝 발표일 기준 ±5일 주가 변화를 자동 계산해 패턴 분석

- **어닝 당일 갭(Gap)**: 장 전 발표 vs. 장 중 발표 구분
- **섹터 contagion**: NVDA Beat 시 AMD, AVGO, TSM 동반 반응 추적
- **EPS Beat vs. 가이던스 Beat**: 어느 쪽이 주가에 더 영향을 미치는가

---

### 10. 공시 텍스트 LLM 요약 및 인사이트

**제안 방식** (API 키 추가 시):
- Filing 상세 화면에서 "📋 AI 요약 생성" 버튼 클릭 → Claude/GPT API 호출
- 출력 포맷: 핵심 변화, 리스크 요인, 가이던스 변화, 투자 포인트 (4개 섹션)
- 결과를 `llm_summary` 테이블에 캐싱 (동일 Filing 재호출 방지)

---

### 11. 실적 시즌 캘린더 강화

**현재**: 단순 테이블.  
**제안 추가 기능**:
- **월간 캘린더 뷰**: 날짜별로 기업이 배치된 달력 레이아웃
- **시간대 표시**: ET → KST 자동 변환 (한국 시간 기준 새벽 vs. 주간)
- **실적 예측 배지**: 컨센서스 추정치를 캘린더에 미리 표시
- **iCal 내보내기**: `.ics` 파일로 구글 캘린더/아이폰 캘린더에 추가
