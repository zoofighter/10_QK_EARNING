# 10_QK_EARNING — AI 맞춤형 교차 리포트 에이전트 스튜디오 설계서

- **작성일자**: 2026-09-19
- **문서 버전**: v1.0
- **문서 목적**: 사용자의 수동 메모/아이디어와 시스템 내부의 과거 재무 데이터 및 타사 어닝콜을 교차 조회(Cross-Referencing)하여 고품질 투자 보고서를 자동 생성하는 AI 에이전트(Agentic RAG) 스튜디오 설계

## 1. 배경 및 도입 목적

### 1.1 사용자의 핵심 니즈
* 사용자가 직접 정리한 핵심 메모, 가설, 수동 요약문 또는 외부 리포트 발췌문을 바탕으로 새로운 종합 분석 보고서를 작성하고자 함.
* 단일 기업의 실적만 나열하는 것이 아니라, **과거 시계열 데이터(2020~2026) 및 밸류체인 내 다른 연관 기업들의 실적/발언을 교차 대조(Cross-Reference)**하여 입체적인 시각을 도출하고자 함.

### 1.2 "단순 프롬프트 + LLM"의 한계와 AI 에이전트의 당위성
* **단순 프롬프트(One-shot Prompting)의 3대 한계**:
  1. **컨텍스트 초과 및 환각(Hallucination)**: 34개 기업의 수개년 재무 데이터와 23개 어닝콜 전문(수만 단어)을 프롬프트 하나에 다 담을 수 없으며, 담더라도 'Lost in the middle' 현상으로 사실을 왜곡함.
  2. **능동적 데이터 탐색 불가**: 사용자 메모를 보고 "어떤 테이블의 어떤 숫자를 가져와야 하는지" 모델이 스스로 쿼리할 수 없음.
  3. **숫자의 정밀도 결여**: 모델의 기억에만 의존하면 매출액, 영업이익률, CapEx 숫자가 부정확해짐.
* **해결책 (AI Agent / Tool-Calling 방식)**:
  * 모델이 사용자의 작성 의도와 목차를 파악한 뒤, **시스템의 SQLite 데이터베이스 쿼리 함수(Tools)를 스스로 호출하여 정확한 팩트 수치만을 인출한 후 글을 작성**함.

## 2. 모델 선택지: 로컬 Qwen 2.5 vs 무료 클라우드 LLM

비용 0원(완전 무료)으로 강력한 에이전트를 구동하기 위해 **원클릭 모델 스위처(하이브리드)** 구조를 적용합니다.

```text
┌─────────────────────────────────────────────────────────────┐
│ ⚙️ AI 추론 엔진 선택:                                      │
│  ● [로컬] Qwen 2.5 (Ollama - 내 맥북 로컬 구동 / 보안 100%)    │
│  ○ [클라우드] Google Gemini 1.5 Flash (무료 API / 100만 토큰)│
│  ○ [클라우드] Groq Cloud Llama-3.3-70B (초고속 무료 API)     │
└─────────────────────────────────────────────────────────────┘
```

| 구분 | [로컬] Qwen 2.5 (Ollama) | [클라우드] Google Gemini 1.5 Flash |
|:---|:---|:---|
| **비용** | 100% 무료 (0원) | 100% 무료 (Google AI Studio 하루 1,500회 무료) |
| **보안** | **완벽한 데이터 보안** (로컬 Mac에서만 구동) | 클라우드 API 전송 (SSL 암호화) |
| **컨텍스트** | 32k ~ 128k 토큰 | **100만 토큰 (초장문 소화)** |
| **장점** | 오프라인 구동 가능, 데이터 유출 리스크 제로 | 압도적인 교차 추론 성능, 복잡한 재무 분석 탁월 |
| **구동 방법** | `ollama run qwen2.5:7b` (또는 14b) | 시스템 환경변수 `GEMINI_API_KEY`로 즉시 가동 |

### 2.1 Gemini CLI vs 파이썬 직접 API 호출 방식 비교 및 검증
* **Gemini CLI 서브프로세스 호출 방식**:
  * 파이썬 `subprocess`로 터미널 명령어를 실행할 수 있으나, 프로세스 기동 오버헤드(1.5~2초)와 Tool Calling 반환값 파싱의 복잡성 및 GCP 프로젝트 ID 인증 종속성 존재.
* **파이썬 직접 API 호출 방식 (채택)**:
  * **환경 검증 결과**: 현재 시스템 환경변수에 이미 유효한 `GEMINI_API_KEY`가 탑재되어 있으며, `gemini-2.5-flash` 모델과 직접 통신 시 **0.38초 만에 즉각 응답**함을 실측 확인.
  * 별도 라이브러리 추가 없이 파이썬 표준 라이브러리만으로 4대 DB Tool을 직접 바인딩하여 초고속 에이전트를 가동함.
* **상세 검증 리포트**: [`docs/2026-09-19_Gemini_CLI_vs_API_연동방식_검증보고서.md`](file:///Users/boon/Dropbox/03_code/b_0917_10_QK_EARNING/docs/2026-09-19_Gemini_CLI_vs_API_%EC%97%B0%EB%8F%99%EB%B0%A9%EC%8B%9D_%EA%B2%80%EC%A6%9D%EB%B3%B4%EA%B3%A0%EC%84%9C.md) 참조.

## 3. 목차 템플릿 기반 구조화 작성 (정확도 극대화 원리)

글을 쓸 때 목차(Template Outline)를 사전에 정의하면 다음과 같은 이유로 생성 품질이 3~5배 상승합니다:

1. **도구 호출(Tool Calling) 타겟팅**:
   * 예: 목차에 `[3. SK하이닉스 vs 삼성전자 HBM OPM 비교]`가 명시되어 있으면, 에이전트가 `get_financials('000660.KS')`와 `get_financials('005930.KS')`를 정밀 타겟 쿼리하여 표로 삽입함.
2. **환각 및 불필요한 잡담(Fluff) 차단**:
   * 정해진 목차 슬롯을 채우는 방식으로 작동하므로 뜬구름 잡는 일반론이 제거되고 팩트 밀도가 극대화됨.
3. **월가 애널리스트/IB 리서치급 포맷팅**:
   * 서론-본론-교차대조-리스크-결론의 표준 리서치 포맷을 엄격히 준수.

## 5. 시스템 아키텍처 및 구현 스펙

### 5.1 백엔드 서비스 (`app/services/report_agent.py`)
OpenAI 표준 규격(SDK)을 기반으로 구현하여 로컬 Ollama와 클라우드 Gemini를 100% 동일한 코드로 처리합니다.

```python
# 에이전트에 바인딩할 4대 도구(Tools) 정의
tools = [
    {
        "name": "get_quarterly_financials",
        "description": "기업의 분기별 매출, 영업이익률, 순이익, CapEx, 데이터센터 비중 조회",
        "parameters": {"ticker": "str", "limit": "int"}
    },
    {
        "name": "search_earning_call_transcripts",
        "description": "특정 기업 어닝콜의 발표문 및 Q&A 세션 내 특정 키워드/쟁점 발언 검색",
        "parameters": {"ticker": "str", "query": "str"}
    },
    {
        "name": "get_consensus_and_surprise",
        "description": "분기 실적 컨센서스 대비 서프라이즈율(Beat/Miss) 및 주가 반응 조회",
        "parameters": {"ticker": "str"}
    },
    {
        "name": "get_leading_indicators",
        "description": "DRAM/NAND 메모리 현물가, 관세청 수출액, 빅테크 통합 CapEx 조회",
        "parameters": {"indicator_type": "str"}
    }
]
```

### 5.2 실행 흐름 (Execution Pipeline)
1. **사용자 요청 접수**: 선택된 옵션(기업 목록, 목차 체크리스트, 톤, 메모) 수신
2. **에이전트 Plan 수립**: 목차별로 필요한 데이터베이스 쿼리를 식별
3. **도구 실행 (Tool Execution)**: SQLite DB에서 실제 확정 수치 및 어닝콜 발언 추출
4. **교차 합성 및 작성 (Synthesis)**: 사용자 메모와 조회된 팩트를 목차 구조에 결합
5. **마크다운 렌더링**: 웹 UI에 실시간 스트리밍 출력 및 원클릭 복사/파일 다운로드 지원
