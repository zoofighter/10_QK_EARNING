## 1. 개요 및 목적

### 1.1 배경
지금까지는 10-Q / 10-K 분기 보고서 기반의 정량 재무 지표(매출, OPM, CapEx, 환율 등)를 구조화하여 대시보드에 시각화했습니다.  
그러나 실질적인 반도체 및 AI 빅테크 투자 판단을 위해서는 **실적 발표 컨퍼런스콜(어닝콜)에서 CEO/CFO가 밝힌 정성적 코멘트, 차세대 제품 가이던스(Blackwell, HBM3E, 커스텀 ASIC 등), 그리고 월가 애널리스트들과의 실시간 Q&A 질의응답 전문**을 열람하고 분석하는 기능이 필수적입니다.

### 1.2 목표
1. **어닝콜 수집 파이프라인 구축**: SEC 8-K Exhibit 99.1 공식 코멘터리 자동 수집 + 외부 트랜스크립트 연동 + 사용자 직접 등록 지원.
2. **트랜스크립트 데이터베이스 관리**: `earning_call` 테이블에 전문 텍스트(`transcript_text`), 발언 일시, 출처, 상태를 체계적으로 저장.
3. **대시보드 전용 열람 뷰어 (Transcript Viewer) 구현**: 웹 브라우저에서 분기별 어닝콜 전문을 검색·열람하고, 경영진 주요 발언과 Q&A를 편리하게 확인.
4. **간편 등록 UI 제공**: 사용자가 구한 어닝콜 텍스트를 즉시 붙여넣어 보관할 수 있는 업로드 모달 제공.

## 3. 데이터베이스 설계 (`earning_call`)

```sql
CREATE TABLE IF NOT EXISTS earning_call (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    entity_id INTEGER NOT NULL,
    fiscal_year TEXT NOT NULL,
    fiscal_quarter TEXT NOT NULL,
    call_date TEXT NOT NULL,
    call_time_et TEXT,
    transcript_text TEXT,
    source_url TEXT,
    local_file_path TEXT,
    status TEXT DEFAULT 'REVIEWED', -- PENDING, REVIEWED, PARSED
    created_at TEXT DEFAULT (datetime('now')),
    FOREIGN KEY (entity_id) REFERENCES entity(id) ON DELETE CASCADE,
    UNIQUE (entity_id, fiscal_year, fiscal_quarter)
);

CREATE INDEX IF NOT EXISTS idx_call_entity ON earning_call(entity_id);
CREATE INDEX IF NOT EXISTS idx_call_date ON earning_call(call_date DESC);
```

## 4. 백엔드 서비스 및 API 아키텍처

### 4.1 서비스: `app/services/transcript_collector.py`
- `save_transcript(ticker, fiscal_year, fiscal_quarter, call_date, transcript_text, ...)`: 트랜스크립트 신규 저장/갱신
- `get_transcript(ticker, fiscal_year, fiscal_quarter)`: 특정 분기 어닝콜 전문 및 분석 데이터 조회
- `get_transcripts_list(ticker=None, fiscal_year=None, limit=20)`: 어닝콜 목록 조회
- `seed_sample_transcripts()`: 핵심 기업(NVDA, 000660.KS, MSFT, AVGO 등)의 최신 어닝콜 고품질 실전 데이터베이스 시딩

### 4.2 REST API 엔드포인트
- `GET /api/earning-calls`: 어닝콜 목록 (필터: ticker, fiscal_year)
- `GET /api/earning-calls/<id>`: 어닝콜 상세 내용 및 전문 텍스트 반환
- `POST /api/earning-calls`: 신규 어닝콜 텍스트 수동 등록 (JSON body: ticker, fiscal_year, fiscal_quarter, call_date, transcript_text)

## 5. 프론트엔드 UI/UX 설계

1. **상단 네비게이션/섹션**:
   - `[📞 어닝콜 트랜스크립트 (Earnings Calls)]` 탭
2. **2단 분할 레이아웃 (Split Layout)**:
   - **좌측 사이드바**: 기업 선택 셀렉터 + 분기별 어닝콜 히스토리 카드 목록
   - **우측 메인 뷰어**:
     - 상단 헤더: 기업명, 티커, 분기 라벨, 발표 일시, 출처 배지
     - 핵심 발언 하이라이트 박스 (Executive Summary / Key Takeaways)
     - 어닝콜 전문 스크롤 뷰어 (Prepared Remarks 세션 & Analyst Q&A 세션)
3. **간편 등록 모달 창 (`#modal-upload-transcript`)**:
   - 기업 선택, 분기 선택, 발표일 입력
   - 어닝콜 전문 텍스트에어리어(Textarea) 붙여넣기
   - "저장 및 색인" 원클릭 버튼
