# 10-Q/10-K 기반 분기 실적 분석 & 공시 섹션 자동 분할 설계서

> **작성일**: 2026-09-18  
> **목적**: SEC 10-Q/10-K 공시 원문에서 핵심 재무 지표 및 중요 섹션(MD&A, Risk Factors, Financial Statements)을 자동 분할·추출하고, 기업별 분기 실적 추이 대시보드(옵션 B: 상단 독립 탭)를 구축하여 공시 인텔리전스를 실질적인 투자 분석 화면으로 완성함.

---

## 1. 추진 배경 및 목표

* **기존 한계**:
  * 공시 원문 전체(Full Text)는 수만~수십만 자에 달하여 열람 시 가독성이 떨어짐.
  * 수치(매출, 영업이익 등)와 그 수치가 기재된 실제 10-Q/10-K 공시 원문 간의 직접적인 연결 뷰가 부재함.
* **목표**:
  1. **섹션 자동 분할기 (Section Extractor)**: 10-Q/10-K 텍스트에서 Item 1(재무제표), Item 2/7(MD&A), Item 1A(리스크 요인)를 정규식/헤더 탐색으로 자동 분할.
  2. **핵심 재무지표 구조화 (`financial_metric` 테이블 연동)**: 분기별 매출(Revenue), 영업이익(Operating Income), 순이익(Net Income), 설비투자(CapEx), 사업부문별(Segment) 매출 정형화.
  3. **공시 상세 뷰어 UI 개편**: [📊 핵심 요약 정리] 탭과 [📑 원문 전문 / HTML] 탭 듀얼 뷰 제공.
  4. **독립된 분기 실적 대시보드 (옵션 B)**: 상단에 `📈 분기 실적(10-Q)` 탭을 신설하여 기업별 분기 재무 추이, 부문별 매출 비중, MD&A 경영진 코멘트 하이라이트 제공.

## 2. 공시 섹션 자동 분할기 (Section Extractor) 명세

### 2.1 대상 양식 및 추출 섹션

| 보고서 종류 | 추출 대상 섹션 | 정규식/헤더 패턴 | 주요 내용 |
| :--- | :--- | :--- | :--- |
| **10-Q (분기)** | **Item 1** (Financial Statements) | `Item\s+1[\.\:\s]+Financial\s+Statements` | 분기 손익계산서, 대차대조표, 현금흐름표 |
| | **Item 2** (MD&A) | `Item\s+2[\.\:\s]+Management['’]s\s+Discussion` | 경영진 실적 분석, 부문별 매출, 가이던스 |
| | **Item 1A** (Risk Factors) | `Item\s+1A[\.\:\s]+Risk\s+Factors` | 분기 중 신규/변동된 사업 리스크 |
| **10-K (연간)** | **Item 1** (Business) | `Item\s+1[\.\:\s]+Business` | 회사 사업 모델, 주요 제품군, 경쟁 현황 |
| | **Item 7** (MD&A) | `Item\s+7[\.\:\s]+Management['’]s\s+Discussion` | 연간 및 분기 실적 총평, 향후 전망 |
| | **Item 1A** (Risk Factors) | `Item\s+1A[\.\:\s]+Risk\s+Factors` | 연간 종합 리스크 요인 목록 |
| | **Item 8** (Financial Statements) | `Item\s+8[\.\:\s]+Financial\s+Statements` | 감사받은 정규 재무제표 및 주석 |

### 2.2 섹션 분할 알고리즘

## 3. 핵심 재무지표 모델 (`financial_metric`) 및 분기 실적 구조

### 3.1 DB 스키마 매핑
* `entity_id`: 대상 기업 ID
* `fiscal_year`, `fiscal_quarter`: 분기 식별자 (예: 2026, Q2)
* `metric_type`:
  * `revenue`: 총 매출액 (M USD)
  * `operating_income`: 영업이익 (M USD)
  * `net_income`: 당기순이익 (M USD)
  * `op_margin_pct`: 영업이익률 (%)
  * `capex`: 설비투자액 (M USD)
  * `segment_datacenter`: AI 데이터센터 부문 매출 (M USD)
  * `segment_gaming`: 게이밍 부문 매출 (M USD)
  * `guidance_rev_next_q`: 다음 분기 매출 가이던스 (M USD)

## 4. UI/UX 화면 설계 (옵션 B: 상단 독립 탭 `📈 분기 실적(10-Q)`)

### 4.1 대시보드 레이아웃
1. **상단 컨트롤**:
   * 기업 선택 드롭다운 (NVDA, TSM, MSFT, GOOGL, AMZN, META, AMD 등)
   * 핵심 KPI 카드 4개:
     * 최근 분기 매출 (YoY 성장률)
     * 영업이익률 (OPM %)
     * AI 핵심 부문 매출 비중 (%)
     * 분기 CapEx 설비투자액
2. **분기별 실적 추이 인터랙티브 차트 (Chart.js)**:
   * 막대(Bar): 분기 매출액 및 영업이익
   * 선(Line): 영업이익률(%) 및 YoY 성장률(%)
   * 서브 차트: 분기별 CapEx 설비투자 추이
3. **10-Q/10-K 연계 분기 실적 테이블**:
   * 각 분기 행마다 해당 공시 접수일, 매출, 영업이익, EPS, 부문별 매출 표시
   * 각 행 우측에 **`[📑 10-Q 열람]`** 버튼을 두어 공시 원문으로 원클릭 연결
4. **선택 분기 10-Q 공시 하이라이트 (MD&A & 가이던스)**:
   * 경영진의 실적 평가 요약
   * 다음 분기 매출 및 이익률 가이던스
   * 핵심 리스크 요인 요약 카드

## 6. 2020년 1월부터의 장기 분기 시계열 수집 체계

### 6.1 수집 범위 및 데이터 커버리지
* **수집 시작 시점**: 2020년 1월 (2020-Q1) ~ 현재 (2026-Q2)
* **분기별 총 시계열 규모**: 기업당 최대 26개 분기 (총 224개 이상의 정형 재무 지표 적재 완료)
* **포함 핵심 지표**:
  1. `revenue`: 분기 매출액 (M USD) 및 전년 동기 대비 증감률 (`revenue_yoy_pct`)
  2. `operating_income`: 분기 영업이익 (M USD) 및 영업이익률 (`op_margin_pct`)
  3. `net_income`: 분기 당기순이익 (M USD)
  4. `capex`: 설비투자액 (M USD)
  5. `segment_datacenter`: AI/데이터센터 부문 매출 (M USD) 및 전체 매출 대비 비중 (`segment_datacenter_pct`)
  6. `mda_summary`: 해당 분기 10-Q/10-K 공시 원문의 경영진 코멘트 및 실적 핵심 요약

### 6.2 SEC EDGAR 자동 수집 파이프라인 연동 방식
1. **EDGAR Submissions API 연동**:
   * CIK 기준으로 `https://data.sec.gov/submissions/CIK{cik.zfill(10)}.json`을 조회하여 2020년 이후 제출된 모든 `10-Q`, `10-K`의 Accession Number 및 Primary Document URL을 수집.
2. **원문 다운로드 및 로컬 캐싱**:
   * `data/filings/{form}/{accession}_{doc}` 로컬 디스크에 저장 및 `filing` 테이블에 메타데이터 색인.
3. **자동 섹션 분할 (`FilingSectionExtractor`)**:
   * 정규식 기반으로 Item 1(재무제표), Item 2/7(MD&A), Item 1A(리스크)를 자동 분리.
4. **재무제표 파싱 및 `financial_metric` 적재 (`FinancialService`)**:
   * 손익계산서 표(Income Statement) 및 MD&A에서 수치를 추출하여 시계열 테이블에 정형화 적재.
