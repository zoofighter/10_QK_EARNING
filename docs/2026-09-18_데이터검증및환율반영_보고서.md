## 3. 환율(FX Rate) 및 원통화 표시 컬럼 추가

글로벌 기업 간 표준 비교(USD)를 유지하면서도 해외 기업의 본국 공시 통화 기준을 투명하게 안내하기 위해 다음 3단계 확장을 구현했습니다:

1. **DB 스키마 확장 (`financial_metric`)**:
   - `fx_rate` (REAL DEFAULT 1.0): 적용 환율 (예: 1350 for KRW)
   - `original_currency` (TEXT DEFAULT 'USD'): 공시 통화 코드 (`KRW`, `JPY`, `EUR`, `TWD`, `USD`)
2. **백엔드 API (`/api/financials/<ticker>`)**:
   - `fx_rate_label`: 뱃지용 텍스트 (예: `₩1,350/$ (KRW)`, `¥155/$ (JPY)`, `€0.92/$ (EUR)`, `USD (기준)`)
   - `original_revenue_str`: 원통화 금액 환산 표기 (예: `약 79.3조원`, `약 171.5조원`, `€6.9B`)
3. **프론트엔드 UI (`static/index.html` 및 `static/js/app.js`)**:
   - 테이블 헤더: **`적용 환율 (FX)`** 컬럼 신설
   - 매출액 열: 달러 금액 바로 하단에 **원통화 환산액** 함께 표시 (예: `$58.8B (+383.1%) / 약 79.3조원`)
