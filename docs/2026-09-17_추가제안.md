## 1. 데이터 수집 확장

### 1-1. 인사이더 거래 (SEC Form 4)

| 항목 | 내용 |
|------|------|
| **설명** | 경영진/이사회의 자사주 매수·매도 내역 |
| **가치** | 대규모 인사이더 매수 = 경영진 확신 시그널, 실적 발표 전 매도 = 주의 |
| **수집** | SEC EDGAR API (`form="4"`) — EdgarTools로 자동 수집 가능, 무료 |
| **난이도** | ⭐ 쉬움 (기존 파이프라인 재활용) |
| **우선순위** | ⭐⭐⭐ |

### 1-2. 재고 수준 (Inventory) 추적

| 항목 | 내용 |
|------|------|
| **설명** | 분기별 재고 금액, 재고일수(DOI), 재고/매출 비율 |
| **가치** | 반도체 사이클의 **핵심 선행지표**. 재고 급증 → 수요 둔화 시그널, 재고 감소 → 공급 부족 |
| **수집** | 10-Q Balance Sheet에서 자동 추출 (F3 파이프라인 확장) |
| **난이도** | ⭐ 쉬움 (metric_type='inventory' 추가) |
| **우선순위** | ⭐⭐⭐ |

### 1-3. 중국 매출 비중 추적

| 항목 | 내용 |
|------|------|
| **설명** | 기업별 중국(Greater China) 매출 비중 (%) |
| **가치** | 미중 갈등·수출통제 리스크 핵심 지표. NVDA/AMAT/LRCX 등 중국 매출 변동이 실적에 직결 |
| **수집** | 10-Q/10-K의 Geographic Revenue Breakdown에서 추출 (규칙 기반 + LLM) |
| **난이도** | ⭐⭐ 보통 (파싱 난이도 높음, 기업마다 형식 다름) |
| **우선순위** | ⭐⭐⭐ |

### 1-4. R&D 투자 추적

| 항목 | 내용 |
|------|------|
| **설명** | 분기별 R&D 지출 금액, R&D/매출 비율 |
| **가치** | AI 투자 강도 측정. R&D 비중 상승 = 장기 성장 투자, 하락 = 수익성 우선 |
| **수집** | 10-Q Income Statement에서 자동 추출 |
| **난이도** | ⭐ 쉬움 (metric_type='rd_expense' 추가) |

### 1-5. Book-to-Bill 비율 (장비사 전용)

| **우선순위** | ⭐⭐ |

### 1-6. 매크로 지표 (반도체 관련)

## 2. 분석 기능 고도화

### 2-1. 어닝콜 센티먼트 분석

| 항목 | 내용 |
|------|------|
| **설명** | 키워드 빈도를 넘어, 어닝콜 전체의 **감성(긍정/부정/중립)** 점수화 |
| **가치** | "경영진이 이번 분기 얼마나 자신감 있게 말했는가"를 수치화 |
| **구현** | LLM에 트랜스크립트를 넣고 1~10점 척도로 센티먼트 스코어링 |
| **우선순위** | ⭐⭐⭐ |

### 2-2. 가이던스 정확도 추적

| 항목 | 내용 |
|------|------|
| **설명** | 기업이 제시한 가이던스 vs 실제 실적을 비교하여 "가이던스 신뢰도" 측정 |
| **가치** | 가이던스를 보수적으로 주는 기업(NVDA) vs 공격적으로 주는 기업 구분 |
| **구현** | `financial_metric`에서 guidance vs actual 매칭, 오차율 자동 계산 |
| **우선순위** | ⭐⭐⭐ |

### 2-3. 교차 언급 추적 (Cross-Mention)

| 항목 | 내용 |
|------|------|
| **설명** | 어닝콜에서 다른 기업을 언급하는 횟수·맥락 추적 |
| **가치** | MSFT가 어닝콜에서 "NVIDIA"를 15회 언급 → AI 칩 수요 강세 시그널 |
| **구현** | 34개 기업명 사전으로 교차 검색, 언급 컨텍스트 발췌 |
| **우선순위** | ⭐⭐⭐ |

### 2-4. 어닝콜 Q&A 다이나믹스

| 항목 | 내용 |
|------|------|
| **설명** | 어떤 애널리스트가 질문했는지, 어떤 토픽에 집중했는지 분석 |
| **가치** | 월가 관심사 추적 (예: "이번 분기 7명 중 5명이 중국 매출에 대해 질문") |
| **구현** | Q&A 섹션 파싱 → 질문자/질문 토픽 분류 |
| **우선순위** | ⭐⭐ |

### 2-5. 실적 시즌 서머리 자동 생성

| 항목 | 내용 |
|------|------|
| **설명** | 한 분기 실적 시즌이 끝나면 34개 기업 전체를 종합하는 "시즌 리포트" 자동 생성 |
| **가치** | "2026-Q2 실적 시즌 요약: L2 하이퍼스케일러 CapEx +35% YoY, AI 키워드 언급 역대 최다" |
| **구현** | LLM에 전체 기업 데이터를 넣고 종합 리포트 생성 |
| **우선순위** | ⭐⭐⭐ |
